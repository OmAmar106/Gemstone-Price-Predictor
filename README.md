# 💎 Gemstone Price Predictor 💎

## 🚀 Overview

Predict gemstone prices using machine learning! This project analyzes key gemstone features like carat, cut, color, and clarity to estimate their market value

## ⚙️ Installation

1. Clone the repo:

   ```bash
   git clone https://github.com/OmAmar106/Gemstone-Price-Predictor.git
   cd Gemstone-Price-Predictor
   ```

2. Create & activate a virtual environment:

   ```bash
   python -m venv venv
   source venv/bin/activate
   ```
